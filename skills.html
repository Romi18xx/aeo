Method

How the skill pack works

  1. 1

    Skills live as Markdown playbooks

    Each entry here is a SKILL.md under .claude/skills/ — a playbook Claude follows for that job, with reference docs and examples alongside it.

  2. 2

    Claude matches the task automatically

    Describe what you need in plain language and Claude reads the trigger phrases in each skill's description to pick the right one — no need to memorize this list.

  3. 3

    Or invoke one by name

    Know exactly which skill you want? Type /skill-name to run it directly. The 51 general-purpose skills are version-pinned in skills-lock.json; the 4 Brand Content Engine skills are custom to this repo and share state through .claude/brand-memory.json.
