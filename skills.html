Method

How agents and skills fit together

  1. 1

    Skills are the playbooks

    Each catalog entry is a SKILL.md under .claude/skills/ — a specific, narrow playbook (write an ad, audit SEO, plan a launch) with references and examples alongside it.

  2. 2

    Agents are the department heads

    Each domain agent is a .claude/agents/<name>.md system prompt that owns a cluster of skills, decides how to use them, and hands off to another agent when a task crosses domains — Strategist plans, Wordsmith writes, Growth acquires, Lifecycle converts and retains, Signal owns search and AI visibility.

  3. 3

    Invoke either one directly

    Describe a task in plain language and Claude routes it to the right agent or skill automatically, or name one yourself: /skill-name for a specific playbook, or ask for an agent by name (e.g. "have Growth look at this") to delegate the whole task.
